## 1. 工程原则

### 1.1 共性问题一次解决（不逐点打补丁）

同一类问题出现在多条路径时，必须抽公共层一次性修复所有路径，不允许只修被发现的单点、反复返工。

- **案例教训**：内镜轮廓断开只修了 `step_topology.py`，后挡风（`step_rear_window.py`）同样的问题没修——浪费时间。正确做法是抽公共实现。
- **公共层模式**（STEP 提取三路径 内镜/外镜/后挡风 共用）：
  - 顶点锚定采样 `sample_edge_vertex_chained`（修复 B-spline 采样不落共享顶点的飞线）
  - 自检闸门 `step_verify.assert_outline_ok`（连续闭合/无飞线/跨度合理）
  - 重复描边清理 `strip_doubled_paths`（CAD 退化环「出去又折回」）
  - 半模镜像 `mirror_half_outline`（半边建模 → 完整轮廓）
  - 多文件合并 `parse_and_merge`（多个 STEP 实体/点 ID 重编号合并）
- **新发现问题时先问**：这个问题的类是什么？其他路径有没有同类隐患？一并处理。

### 1.2 布局对不齐：先 diff DOM 结构，再动 CSS

- **案例**：内镜判据面板与角度卡之间水平间隙过大，外镜正常。先后 4 次调 CSS 只让问题移动一点点，浪费约 1 小时。真根因是内镜判据面板多套了一层 `<div id="verdict">` wrapper，外镜没有。
- **教训**：调同类两页面布局对不齐时，第一步永远是 diff DOM 结构（肉眼对比标签层级），看到 wrapper div 数不一致先怀疑结构冗余，再考虑 CSS。
- **副作用提醒**：改 DOM 结构必须同步审视所有引用该 id 的 JS（案例：去掉 wrapper 后 `querySelector('.alert')` 变 null 导致校核时抛错）。

### 1.3 精度保证（工具校核的信任基础）

任何从 STEP 提取的轮廓必须满足，否则不能用于校核：

| 保证项 | 标准 | 方法 |
|---|---|---|
| 无飞线 | 相邻点间隙 ≈ 0 | VERTEX_POINT 链式缝合（顶点严格在曲面上，是模型真实边界点） |
| 点在曲面上 | 偏差 < 0.5mm | 提取后校验距球心 |
| 连续闭合 | 闭合间隙 ≈ 0 | 顶点闭合 |
| 球心吻合 | 与供应商偏差 < 5mm | crossCheck 交叉校核 |

### 1.4 提交与验收

- **提交前必须经确认**：改动完成后先汇报改了什么 + 测试结果，用户明确授权（「提交」「提交一版」）才 commit。
- **独立验收**：不是只看执行结果，要实际跑（`npm test` + 对照数据 + 安全测试）。
- **提交后验收**：`node --check` + `npm test` + Python 回归测试，全绿再推送。

## 2. 前端设计理念

用户 2026-08 认可并要求作为以后所有设计的设计基线：

- **居中美学**：卡片/内容在视口内垂直水平居中，顶栏固定顶部不动，不偏上偏下。
- **克制**：无 emoji、无花哨特效，冷白 Apple 风；「恰到好处」不等于特效。
- **黄金比例卡**：选择卡 360×222px（宽÷1.618），文字居中，内边距 32/36px，间距走 8pt 网格。
- **内容够用即止**：不铺满全页；表单型向导收窄到 640px（输入不拉伸），选择页容器 800px。
- **颜色语义（工作流区分）**：绿 `#34c759` = 已有/就绪，蓝 `#0071e3` = 新建/动作。实心绿按钮需用更深一档绿（如 #1e8f41）保证白字对比度。
- **字数不强制对齐**：标题等长差靠居中平衡，不造词凑字数。
- **视觉中心**：每页要有视觉中心，卡片不拥挤也不悬浮。

## 3. 已知问题与边界

### 3.1 外镜右镜 FAIL（几何极限，已定论）

LHD 右外镜视野校核 FAIL **不是代码 bug、不是数据错误、不是模型问题**，是物理几何极限：

- 驾驶员在左侧，右镜在右侧，眼点→帽心距离是左镜的约 1.85 倍
- 同样尺寸球面帽，左镜刚好覆盖 III 类近场 1m 宽，右镜只覆盖靠车门侧约 0.4m
- ±30° 旋转全 FAIL，margin=0 也无效（off-surface 的根本在镜面上没有反射点）
- 排除项全部验证：判据口径 / 数据不对称 / 调节范围 / margin 阈值
- **结论**：等供应商反馈（右镜玻璃加大 / 改安装位置 / 降 II 类 / 接受 FAIL）

### 3.2 后挡风图例显示问题（已修复）

Plotly 视图图例不显示的根因是**渲染高度不确定**：只设容器 CSS 高度 + `responsive:true` 时，Plotly 不一定吃容器高度，图例的 paper 坐标（相对 plot 高度）位置跟着漂移。修复：`layout.height` 显式给定（内镜/后挡风按内容比例动态算，外镜固定 520px），图例 y 用固定像素偏移换算。

### 3.3 上传卡住的排查方向

STEP 上传偶发「卡住」的排查方向：服务端单线程 + 后台 Python 提取（spawn 子进程解析大 STEP）竞争 CPU。先确认没有残留 Python 进程与后台测试在抢资源，再查代码。

## 5. AI 协作分工（历史记录）

2026-08-05 曾确立的开发分工（后续会话中已演变为单 agent 全流程，此处仅作历史记录）：

- **plan/accept 角色**：制定开发计划 + 独立验收（对照数据 + 断言 + 安全测试）
- **execute 角色**：按计划写代码，产出对照数据供验收
- 每个 stage 闭环：计划 → 派执行 → 独立核验 → 提交

核心不变的是：**验收不靠「跑通了」口头通过，必须实际跑测试/对照数据**。
